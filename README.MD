## 📌 Overview

**youDigit** is a professional agency landing page built with pure HTML, CSS, and JavaScript — no frameworks, no dependencies. It represents the youDigit brand: a digital agency based in Sri Lanka that builds custom web solutions, smart business tools, and digital growth engines for local and global clients.

---

## ✨ Features

### 🎨 Design & UX
- **Dark glassmorphism aesthetic** with a deep navy/dark blue base and cyan + lime green accent palette
- **Animated hero section** with floating particle effects and a grid overlay
- **Typewriter effect** cycling through key value propositions: *Digital Presence, Custom Web Apps, Smart Solutions, Business Growth*
- **Neon cursor trail** that follows the mouse with a smooth fluid animation
- **Scroll reveal animations** — sections fade and slide in as the user scrolls
- **Animated stat counters** that count up when scrolled into view

### 📐 Layout & Sections
| Section | Description |
|---|---|
| **Hero** | Full-screen intro with headline, CTA buttons, and live stats |
| **Services** | 6-card grid — Custom Websites, Web Apps, E-Commerce, Dashboards, SEO, Automation |
| **Why Us** | Rotating circle visual + key differentiators (5★ rating, custom builds, 24/7 support) |
| **Process** | 5-step workflow: Discovery → Design → Develop → Launch → Grow |
| **Tech Stack** | 12 technology badges (React, Spring Boot, Node.js, Docker, AWS, etc.) |
| **Contact / CTA** | Direct links to email, WhatsApp, Instagram, and Facebook |
| **Footer** | Brand column, services links, company links, and social connect |

### 📱 Responsive & Interactive
- **Hamburger mobile menu** with smooth open/close transitions
- **Sticky navbar** with scroll-triggered glass effect
- **Active nav link highlighting** based on current scroll position
- **Fully responsive** layout adapting to all screen sizes

## 🚀 Getting Started

### Run Locally

Just open the file in your browser:

```bash

start index.html

# Option 2 — Use a local dev server (e.g. VS Code Live Server)
# Right-click index.html → Open with Live Server
```
